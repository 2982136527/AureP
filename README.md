# AureP

AureP 是一款面向手机端的 Emby 播放器，主打快速浏览、顺滑播放和断点续播。

## 现在已支持

- 多服务器保存、切换、编辑和删除
- 首页推荐、继续观看、今日活动进行时
- 资料库浏览、分区切换、排序和媒体卡片展示
- 搜索影片、剧集、演员、标签和媒体库内容
- 详情页查看封面、标题图、演员、剧照、标签和简介
- 播放页断点续播、字幕选择、倍速、播放方式切换和实时码率显示
- 播放手势控制：左侧亮度、右侧音量、左右滑动快进后退
- 兼容 STRM、直连和 302/原链等播放链路
- 记住播放进度和继续观看历史
- 持续优化封面、fanart、标题图和字幕加载体验

## 未来可能更新

- 更强的格式兼容和解码策略
- 更智能的字幕自动匹配
- 更完整的电视、平板布局适配
- 离线缓存和下载能力
- 更细的播放策略与网络模式控制
- 更丰富的收藏、历史和标签浏览
- 更进一步的性能优化和预加载

## 说明

- 具体播放效果取决于服务器能力、网络环境和设备解码能力。
- AureP 会持续围绕手机端体验做优化。
