# Netflix Frontend Prototype

这个目录对应的原型代码位于：

- `app/src/main/java/com/qiuhu/embyflow/ui/netflix/`

当前策略：

- 不直接替换现有 AureP 主线界面
- 先单独做一套 Netflix 风格首页骨架
- 把视觉语言、模块结构和交互节奏拆出来验证
- 等原型稳定后，再决定是否接入真实入口或部分吸收进主线

建议复刻方向：

- 黑色基底 + 强层级横向内容排布
- 大 Hero Banner + 更克制的信息密度
- 标题行、横向 Row、预览位、继续观看位分层
- 更像内容分发平台，而不是当前这套 editorial 卡片语言

注意：

- 可以学习布局结构、动线和内容组织方式
- 不建议直接复制 Netflix 的品牌素材、文案和图标体系
